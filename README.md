# Idiomas em Foco

Plataforma educacional estática de português e espanhol.

## Arquivos
- index.html — estrutura
- style.css — visual responsivo
- script.js — frases, quizzes, pontuação e interações

## Publicação no GitHub Pages
1. Crie um repositório chamado `idiomas-em-foco`.
2. Envie os três arquivos para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Escolha a branch `main` e a pasta `/root`.
5. Salve e aguarde a publicação.
6. O GitHub mostrará o endereço público da plataforma.

## Como atualizar
Edite `PHRASES`, `PT` e `ES` no início de `script.js` para inserir novos conteúdos.
